# Instrucciones obligatorias para agentes de diseño — VALIA / AXIA

**NORMA NO NEGOCIABLE:** Antes de crear o modificar UI, sitio web, deck, PDF, mail HTML, calculadora, campaña, plantilla, infografía o cualquier pieza visual de AXIA, leer y aplicar `docs/brand/AXIA_DESIGN_STANDARD.md` y, cuando esté disponible, el PDF maestro `AXIA Brandbook(8).pdf` (junio 2026).

- Paleta **única AXIA**: `#1C1A32`, `#D8D8E1`, `#C3EE10`, `#E4368A`, `#1000BD`, `#F5F5F5`.
- Tipos: **Afacad** (principal), **Stack Sans Text** (secundaria).
- Logo: **activo original intacto**, nunca recreado o alterado; fondos oscuros logo lima, claros magenta.
- Sin excepciones creativas, sustituciones de color o fuentes, ni logos de texto improvisados.
- Probar visualmente el resultado y CTA reales antes de entregar.
- Distinguir **marca corporativa VALIA** y **marca de producto AXIA**; el manual adjunto es AXIA, no inventar un manual corporativo VALIA inexistente.
- No modificar diseño aprobado salvo lo solicitado; la regla se aplica a toda pieza nueva y a cualquier fragmento que sea rediseñado.

**Un resultado que incumpla estas reglas NO está listo para uso comercial.**
